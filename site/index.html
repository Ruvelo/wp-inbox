Everything that concerns you, in one place

WordPress 7.1's Notes create mentions and replies with nowhere to collect them. Comments, scheduled posts and other plugins too. Now they land in an inbox, and each person decides what also reaches their email.

Our promises

Install it on a hundred client sites without wondering what it will show or become.

  • No nags, no "pro"No admin notices, no review requests, no upsells. And the inbox never carries Ruvelo's own messages.

For developers

Send from any plugin with one line, without depending on this one. Register your types and they appear in everyone's preferences. A REST API, WP-CLI and Abilities API registrations come with it.

Send, with no hard dependency

do_action('ruvelo_inbox_notify', $user_ids, [
    'type'  => 'invoice_paid',
    'title' => 'Invoice INV-2288 paid',
    'body'  => 'Bluefin Studio paid €4,800.00.',
    'url'   => $url,
]);

Let people choose

do_action('ruvelo_inbox_register_type', 'invoice_paid', [
    'label'    => 'Invoice paid',
    'group'    => 'Billing',
    'defaults' => ['email' => true],
]);

wp ruvelo-inbox send maya --title="Export ready"
